addlogprob

Group correctness, stage syntax.

Corset.Rules.Addlogprob — Module

addlogprob (F112): @addlogprob! adds density term outside ~.

Description

Reports DynamicPPL @addlogprob! calls, bare or through Turing. or DynamicPPL..

Rationale

DynamicPPL adds number to log likelihood. Prior term written so is lost under Prior() sampling and counted by maximum likelihood. Term has no variable: rand, predict and pointwise_loglikelihoods skip it, so predictive checks and PSIS-LOO miss it.

Example

@model function scale(x)
    σ ~ Exponential()
    @addlogprob! sum(logpdf.(Laplace(0, σ), x))
end

Alternative

@model function scale(x)
    σ ~ Exponential()
    x ~ filldist(Laplace(0, σ), length(x))
end

Density without Distributions.jl type: define Distribution subtype with logpdf, rand and support bounds.

Limitations

Patterns match syntax as written: macro imported under other name passes.

ambiguous-concat

Group correctness, stage syntax.

Corset.Rules.AmbiguousConcat — Module

ambiguous-concat (F1): space before sign in array literal starts new element.

Description

Reports array literal row where space before - or + splits one expression into two elements: [a -b].

Rationale

Inside brackets, a -b is two elements and a - b is one. Spacing silently changes shape and length of result.

Example

offsets = [width -margin]

Alternative

offsets = [width - margin]   # difference
offsets = [width, -margin]   # two elements

Limitations

Finding is possible: row of signed numbers can be intended.

and-or-precedence

Group readability, stage syntax.

Corset.Rules.AndOrPrecedence — Module

and-or-precedence (F106): && on right of || binds tighter than reader expects.

Description

Reports || whose right operand starts with && without parentheses: a || b && c, a || b && c || d.

Rationale

&& binds tighter than ||, so a || b && c is a || (b && c). Read left to right, it looks like (a || b) && c. Guard done || empty && return never returns when done holds.

Example

state === nothing || values === nothing && return nothing

Alternative

(state === nothing || values === nothing) && return nothing

Limitations

a && b || c is (a && b) || c, as left-to-right reading gives; rule leaves it alone. Fix keeps meaning and adds parentheses: a || (b && c). Check that code means it.

annotation

Group readability, stage syntax.

Corset.Rules.Annotation — Module

annotation (F71): argument or result without type.

Description

Reports named function definition with untyped argument or no result type, once per method. Cause labels mark each untyped argument and missing result type.

Rationale

Signature is first thing reader sees. Types there say what function accepts and returns without reading body. Result annotation also acts as check: result-conversion reports annotation that converts.

Example

area(width, height) = width * height

Alternative

area(width::Real, height::Real)::Real = width * height

Limitations

Exempt: _ and unnamed ::T arguments, keyword splat (Julia rejects its type), anonymous functions, and local functions (closures). Abstract types are intended. ::Any accepts anything on purpose and opts out. Fix guesses types from inference: argument types package calls pass, literal default values, and result types. Each widens to its family (Real, AbstractVector{<:Real}, abstract supertype of struct). Argument guess is breaking: callers outside package can pass other types. Result guess is likely when inference covers every argument type: all arguments typed, keywords included, and no signature skipped. Else it is breaking. Keyword arguments, splats and destructured arguments keep manual fix. Method without package caller keeps it too. Script and run without package get no guess.

approx-zero

Group correctness, stage syntax.

Corset.Rules.ApproxZero — Module

approx-zero (F10): approximate compare to zero without atol holds only for exact zero.

Description

Reports x ≈ 0 and isapprox(x, 0) with literal zero and no atol. Test macro argument atol counts: @test x ≈ 0 atol = 1e-8 passes it to isapprox.

Rationale

isapprox uses relative tolerance by default. Relative to zero, no nonzero value is close, so test passes only when value is exactly zero.

Example

converged = residual(x) ≈ 0

Alternative

converged = isapprox(residual(x), 0; atol = 1e-8)

Limitations

Rule sees literal zero only. Zero held in variable passes.

baked-state

Group correctness, stage syntax.

Corset.Rules.BakedState — Module

baked-state (F100): precompile bakes run-time value into global.

Description

Reports global assigned at module top level from expression that reads run-time state, in package code only. State: thread count, ENV, home, working and temporary directory, clock, random numbers, host name, process ID, pointers. Top level spans module body, begin, if, global in let, @static and @eval. Function bodies, closures and __init__ run later and pass. Arguments of other macros pass: macro decides whether they run. Scripts never precompile, so rule skips them.

Rationale

Precompile runs module top level once and stores globals in cache. Each later session loads value of build session: wrong thread count, old path, null pointer.

Example

const NTHREADS = Threads.nthreads()

Alternative

const NTHREADS = Ref(0)
__init__() = NTHREADS[] = Threads.nthreads()

Limitations

Rule sees state read inside assigned expression. Value passed through local variable, or read in if condition, passes. Assignment in top-level for, while or try passes. Closure called at once, as in foreach(f) do … end, passes.

banned

Group readability, stage syntax.

Corset.Rules.Banned — Module

banned (F82): code matches project ban.

Description

Reports code that matches banned entry in [preferences.Corset]: Argus pattern, or name regex over bound names. Name regex must match whole name; bound names are parameters, assignment targets, loop variables, definition names and fields. Each entry gives reason, which finding shows. All entries share one level, as Clippy disallowed_methods.

Rationale

Project rules outside Corset footguns: house conventions, retired APIs, caution markers such as ccall that need review.

Example

[preferences.Corset]
banned = [
    { pattern = "@show({_}...)", reason = "debug print; use `@debug`" },
    { name = "tmp.*", reason = "name what value holds" },
]

Alternative

Follow reason of entry.

Limitations

Patterns match syntax as written: alias or import under other name passes.

Group correctness, stage syntax.

Corset.Rules.BracketedRange — Module

bracketed-range (F2): range in brackets is one-element vector.

Description

Reports vector literal whose only element is range: [1:n].

Rationale

[1:n] holds one range, not n numbers. Loop over it runs once, and length returns 1.

Example

for i in [1:n]
    total += i
end

Alternative

for i in 1:n
    total += i
end
values = collect(1:n)   # when vector is needed

Limitations

Finding is possible: vector of ranges can be intended. Fix writes collect(range) with tier likely.

broad-catch

Group safety, stage syntax.

Corset.Rules.BroadCatch — Module

broad-catch (F59): catch handles every error.

Description

Reports catch block that neither tests error type nor passes error on.

Rationale

Bare catch also catches InterruptException, OutOfMemoryError and bugs such as MethodError, then hides them.

Example

value = try
    parse(Int, text)
catch
    0
end

Alternative

value = try
    parse(Int, text)
catch error
    error isa ArgumentError || rethrow()
    0
end

Limitations

Rule accepts isa test on caught variable, rethrow, throw and error as narrowing. It does not check that test names right type.

count::Int32 = 0

closed-struct

Group composability, stage package.

Corset.Rules.ClosedStruct — Module

closed-struct (F84): public struct has no abstract supertype, so users cannot add sibling types.

Description

Reports definition of struct with supertype Any when public name refers to it. Public names are names root module exports or declares public, and public names of submodules those names reach.

Rationale

Methods typed on concrete struct accept only that struct. User who needs variant cannot subtype it and must copy or wrap it. Abstract supertype gives users one type to subtype and package one type to dispatch on.

Example

export Model
struct Model
    weights::Vector{Float64}
end
predict(model::Model, x::Vector{Float64})::Float64 = model.weights' * x

Alternative

export AbstractModel, Model
abstract type AbstractModel end
struct Model <: AbstractModel
    weights::Vector{Float64}
end
predict(model::AbstractModel, x::Vector{Float64})::Float64 = model.weights' * x

Limitations

Rule reads struct forms in package files; struct from macro without struct form passes. Public alias counts: const Pairs = Table{Pair} makes Table public.

docstring

Group readability, stage syntax.

Corset.Rules.Docstring — Module

docstring (F74, F80): comment where docstring belongs; module without docstring.

Description

Reports comment block directly above function or struct where docstring attaches, and module without docstring. Docstring attaches at top level, in module body and in begin block; function, let and loop bodies drop it.

Rationale

Help mode (?name) and documentation tools read docstrings only. Comment above definition stays invisible to them.

Example

# Area of circle with radius `r`.
area(r) = π * r^2

Alternative

"""Area of circle with radius `r`."""
area(r) = π * r^2

Limitations

Fix turns comment into docstring as written; review wording after fix.

double-include

Group correctness, stage syntax.

Corset.Rules.DoubleInclude — Module

double-include (F64): same file included twice.

Description

Reports second and later include of same file in one run, and include of entry file Julia already loads (module file, extension, test entry). Paths resolve as discovery resolves them: string literal, raw string, @__DIR__, and joinpath of those.

Rationale

Each include evaluates file again. Struct definitions then throw on redefinition, and methods are defined twice. Including entry file loads it twice, or recurses until stack overflows.

Example

include("utils.jl")
include("solver.jl")   # solver.jl also includes "utils.jl"

Alternative

Include each file once, from module root file.

Limitations

Computed paths pass.

field-prefix (F79): related fields belong in nested struct, table or array.

guard-result

Group readability, stage syntax.

Corset.Rules.GuardResult — Module

guard-result (F114): function result is value of && or || guard.

Description

Reports guard as last value of named function, long form or short form. Guard: chain whose last term exits. || guard gives true when it passes; && guard gives false.

Rationale

Reader cannot tell whether Bool result is API. Caller may come to depend on constant nobody chose.

Example

check(x) = x > 0 || throw(DomainError(x))

Alternative

function check(x)
    x > 0 || throw(DomainError(x))
    return nothing
end

Limitations

Closure and do block pass, since caller picks use of value. Ternary with exit branch gives value of other branch and passes. Fix is manual: add nothing after guard when callers ignore result, or return true when they use it.

implicit-import

Group composability, stage external.

Corset.Rules.ImplicitImport — Module

implicit-import (F65): bare using X brings names module uses without naming them.

Description

Reports bare using X when module uses names X exports; ExplicitImports.jl finds them. Labels mark first use of each name. Fix writes using X: X, name, …; it keeps X, since bare using binds module name too. Names of Base, Core and own package pass.

Rationale

Reader cannot tell where name comes from. Name exporter adds later can clash with own name or other using.

Example

using LinearAlgebra
area(sides) = norm(sides)

Alternative

using LinearAlgebra: LinearAlgebra, norm
area(sides) = norm(sides)

Limitations

using with several modules, as using A, B, gets manual fix. Module ExplicitImports.jl cannot analyze fully (dynamic include, module macro writes) passes.

inference-dependent

Group composability, stage syntax.

Corset.Rules.InferenceDependent — Module

inference-dependent (F26): behavior depends on inference result.

Description

Reports calls to Core.Compiler.return_type, Base.return_types, Base.infer_return_type and Base.promote_op.

Rationale

Inference may widen result at any time: new Julia version, other load order, or changed heuristics. Code that branches on result then takes other path or allocates other type.

Example

T = Base.promote_op(+, eltype(a), eltype(b))
result = Vector{T}(undef, n)

Alternative

result = map(+, a, b)

Limitations

None known.

intermediate-widening

Group performance, stage inference.

Corset.Rules.IntermediateWidening — Module

intermediate-widening (F87): literal or constant makes intermediate run in wider type than input.

Description

Reports weak value that meets generic float input and widens intermediate value, while returned and stored values keep their type: conversion or concrete store narrows result again. Weak values as in type-disruption, which reports widening that escapes.

Rationale

Float32(x * 0.5) computes product in Float64, then rounds back. Work in wider type is slow on GPU and halves SIMD width.

Example

half32(x::AbstractFloat) = Float32(x * 0.5)

Alternative

half32(x::AbstractFloat) = Float32(x * oftype(x, 0.5))

Limitations

Fix converts weak value to input type as type-disruption fix does. It changes rounding of intermediate, so it can change result in last bit. Integer input is exempt, as in type-disruption. Finding is possible when method branches on type or span cannot show weak value.

internal-access

Group composability, stage external.

Corset.Rules.InternalAccess — Module

internal-access (F66): code reaches name other module neither exports nor declares public.

Description

Reports qualified access as Base._sub2ind(…) and import as import Base: _sub2ind of internal name. ExplicitImports.jl finds them. Chain as Base.Precompilation.PkgPrecompileError reports once. Access to own package passes, submodules and extensions included.

Rationale

Owner may rename or remove internal name in any release, with no breaking-change notice.

Example

position(dims::Tuple, row::Int, column::Int) = Base._sub2ind(dims, row, column)

Alternative

position(dims::Tuple, row::Int, column::Int) = LinearIndices(dims)[row, column]

Limitations

Renamed import (using Base: unwrap_unionall as unwrap) passes: ExplicitImports.jl does not report it. Module ExplicitImports.jl cannot analyze fully (dynamic include, module macro writes) reports qualified accesses only.

invariant-parameter

Group correctness, stage package.

Corset.Rules.InvariantParameter — Module

invariant-parameter (F14): argument type with abstract type parameter rejects containers of its subtypes.

Description

Reports abstract type, other than Any, as parameter of parametric type in argument annotation: Vector{Real}.

Rationale

Type parameters are invariant: Vector{Float64} is not subtype of Vector{Real}. Method with values::Vector{Real} accepts only vectors created with element type Real; [1.0, 2.0] raises MethodError. Tuple is covariant and passes.

Example

total(values::Vector{Real})::Real = sum(values)

Alternative

total(values::Vector{<:Real})::Real = sum(values)

Limitations

Rule reads parameters written as names at outer level of annotation; Dict{String, Vector{Real}} and type aliases pass. where bounds pass. Any passes, since Vector{Any} often holds mixed values on purpose.

iteration-mutation

Group correctness, stage effects.

Corset.Rules.IterationMutation — Module

iteration-mutation (F48): collection written inside loop that iterates it.

Description

Reports ! call or field store inside for loop that writes collection loop iterates. View of collection counts: for k in keys(d) iterates d. Size change of same object (push!, delete!, empty!) is definite; other write, or object that can be other, is possible. Writes to elements below collection never count.

Rationale

Loop reads collection by index or slot between steps. Insertion can rehash dictionary or move array elements, so loop skips or repeats elements, or throws. Base filter!(f, ::AbstractDict) warns: "dictionary types may not support mutation during iteration".

Example

function drop_empty!(groups::AbstractDict{String, Vector{Int}})
    for name in keys(groups)
        isempty(groups[name]) && delete!(groups, name)
    end
    return groups
end

Alternative

drop_empty!(groups::AbstractDict{String, Vector{Int}}) = filter!(((_, members),) -> !isempty(members), groups)

Limitations

setindex! on array replaces element: no finding. Deletion from Dict, IdDict, WeakKeyDict, Set, IdSet and BitSet gives no finding: Base deletes from each while iterating it. Closure that consuming call runs (foreach(x -> push!(v, x), v)) stays unseen: its loop is in library code. Write that reaches collection only through object name tier cannot pin (element of zip result) goes to coverage line. Fix is manual.

iterator-traits

Group performance, stage package.

Corset.Rules.IteratorTraits — Module

iterator-traits (F93): iterator without element type makes collect build Vector{Any}.

Description

Reports package struct with Base.iterate method when its IteratorEltype is HasEltype and no method other than Base default covers its eltype. Default IteratorEltype is HasEltype. Return type inference finds trait.

Rationale

Default IteratorEltype is HasEltype, so collect and Set trust eltype. Base default eltype is Any. collect then builds Vector{Any}, and code that reads it is slow. Base.EltypeUnknown() makes collect find element type from values.

Example

struct Countdown
    start::Int
end
Base.iterate(countdown::Countdown, count::Int = countdown.start)::Union{Nothing, Tuple{Int, Int}} =
    count < 1 ? nothing : (count, count - 1)
Base.length(countdown::Countdown)::Int = countdown.start

Alternative

Base.eltype(::Type{Countdown})::Type = Int

Limitations

Abstract types and unions as iterate argument pass; each subtype can define eltype. eltype method that covers only some parameters, as eltype(::Type{Cycle{Int}}), reports. Iterator whose IteratorEltype inference cannot settle to one trait passes, as trait that depends on type parameter.

half = 1/2x

half = 1/(2x)    # or (1/2)x

lost-narrowing

Group performance, stage inference.

Corset.Rules.LostNarrowing — Module

lost-narrowing (F107): type test in && or || chain narrows variable inside chain only.

Description

Reports type test (x isa T, x !== nothing, !isnothing(x)) in && or || chain whose value guards code, when code after guard reads variable as wider type. Guards: (a && b) || return, (a || b) && continue, if !(a && b) return end.

Rationale

Lowering stores chain value before guard branches on it. Inference narrows variable on branch of type test only, so after guard, x is Any again. Each read dispatches at run time, and method that loads later can invalidate code.

Example

function head_args(x)
    (x isa Expr && x.head === :call) || return nothing
    return x.args
end

Alternative

function head_args(x)
    x isa Expr || return nothing
    x.head === :call || return nothing
    return x.args
end

Limitations

Rule sees methods inference reaches, and reports where typed code proves loss: test is not constant, and read after guard has wider type. Lowering branches directly on || chain and if a && b, so they keep narrowing; condition stored in variable (ok = a || b) loses it. Fix splits guard, one guard per term, when guard is own statement, its value goes unused, its exit leaves block (return, continue, break, throw, error, rethrow), and no comment sits inside; else fix is manual.

method-ambiguity

Group correctness, stage external.

Corset.Rules.MethodAmbiguity — Module

method-ambiguity (F94): two package methods match same call, and neither is more specific.

Description

Reports each pair of package methods Test.detect_ambiguities finds, as Aqua.jl does. Finding sits on later definition; cause label marks earlier one. Message names call that matches both.

Rationale

Call that matches both methods throws MethodError, even when no test makes that call. Check covers argument combinations no analyzed caller reaches.

Example

combine(left::Int, right) = left
combine(left, right::Int) = right

Alternative

combine(left::Int, right) = left
combine(left, right::Int) = right
combine(left::Int, right::Int) = left + right

Limitations

Pair with method of other package passes: package alone cannot pick winner. Rule sees definitions in analyzed files of loaded package only. Keyword methods report through their positional methods.

method-overwrite

Group correctness, stage package.

Corset.Rules.MethodOverwrite — Module

method-overwrite (F24): later method definition replaces earlier one with same positional signature.

Description

Reports method definition that replaces earlier definition of same function with same positional argument types.

Rationale

Keywords take no part in dispatch, so f(x; a) and f(x; b) define one method twice. Positional calls reach only later body. When later definition has no keywords, keyword calls still reach earlier body: one function runs two bodies. Julia refuses to precompile package with overwrite, so every using loads package from source.

Example

area(side; scale = 1) = scale * side^2
area(side; units = :m) = side^2

Alternative

area(side; scale = 1, units = :m) = scale * side^2

Limitations

Rule sees definitions in analyzed files of loaded package only.

misplaced-import

Group readability, stage external.

Corset.Rules.MisplacedImport — Module

misplaced-import (F67): explicit import sits in file that uses none of its names; one other file uses them all.

Description

Reports using X: a, import X: a and import X when its own file uses none of its names and exactly one other file of its module uses them. ExplicitImports.jl finds uses. Labels mark first use of each name. Fix moves statement, with its trailing comment, to new line above first statement of module code in that file. Fix tier is likely: moved statement loads its package later, and code that runs between can see that.

Rationale

Julia binds import in whole module, so placement is style. Reader of using file cannot see where name comes from.

Example

# src/Shapes.jl
module Shapes
using LinearAlgebra: norm
include("solve.jl")  # only file that calls `norm`
end

Alternative

# src/solve.jl
using LinearAlgebra: norm

Limitations

Import that several files use passes: module file is its place. Statement that shares line with other code, and target module on one line (module M; …; end), get manual fix. Unused import, bare using and import X: a as b pass. Module ExplicitImports.jl cannot analyze fully passes.

missing-interface

Group correctness, stage package.

Corset.Rules.MissingInterface — Module

missing-interface (F92): struct misses method its Base interface requires; first call that needs it throws.

Description

Reports package struct that misses method Base interface requires:

  • AbstractArray subtype: size(A), and scalar getindex with one Int per dimension. Linear getindex(A, i::Int) counts too when type sets own IndexStyle.
  • AbstractString subtype: ncodeunits(s), codeunit(s, i::Int), isvalid(s, i::Int), iterate(s, i::Int).
  • Struct that package Base.iterate method takes: length(x) when its IteratorSize is HasLength; length(x) and size(x) when it is HasShape. Default IteratorSize is HasLength. Return type inference finds trait.

Method on interface type itself, as getindex(A::AbstractArray, I...), is Base fallback and does not count.

Rationale

Julia checks interface at first call. Missing method throws there, often inside show, collect or map.

Example

struct Ones <: AbstractVector{Float64}
    length::Int
end
Base.size(ones::Ones)::Tuple{Int} = (ones.length,)

Alternative

Reports call to function that eval or @eval defines earlier in same function body.

Rationale

Running function sees only methods that existed when it started. Call right after eval throws MethodError, or runs old method.

Example

function setup()
    @eval helper() = 1
    return helper()
end

Alternative

function setup()
    @eval helper() = 1
    return Base.invokelatest(helper)
end

Core.eval(M, …) and @eval M … define in module M: only call written M.f(…) reaches that definition.

Limitations

Fix is manual when call passes keywords.
