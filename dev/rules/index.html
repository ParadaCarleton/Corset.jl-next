addlogprob

Group correctness, stage syntax.

Corset.Rules.Addlogprob — Module

addlogprob (F112): @addlogprob! adds density term outside ~.

Description

Reports DynamicPPL @addlogprob! calls, bare or through Turing. or DynamicPPL..

Rationale

DynamicPPL adds number to log likelihood. Prior term written so is lost under Prior() sampling and counted by maximum likelihood. Term has no variable: rand, predict and pointwise_loglikelihoods skip it, so predictive checks and PSIS-LOO miss it.

Example

@model function scale(x)
    σ ~ Exponential()
    @addlogprob! sum(logpdf.(Laplace(0, σ), x))
end

Alternative

@model function scale(x)
    σ ~ Exponential()
    x ~ filldist(Laplace(0, σ), length(x))
end

Density without Distributions.jl type: define Distribution subtype with logpdf, rand and support bounds.

Limitations

Patterns match syntax as written: macro imported under other name passes.

ambiguous-concat

Corset.Rules.AmbiguousConcat — Module

ambiguous-concat (F1): space before sign in array literal starts new element.

Description

Reports array literal row where space before - or + splits one expression into two elements: [a -b].

Rationale

Inside brackets, a -b is two elements and a - b is one. Spacing silently changes shape and length of result.

Example

offsets = [width -margin]

Alternative

offsets = [width - margin]   # difference
offsets = [width, -margin]   # two elements

Limitations

Finding is possible: row of signed numbers can be intended.

and-or-precedence

Group readability, stage syntax.

Corset.Rules.AndOrPrecedence — Module

and-or-precedence (F106): && on right of || binds tighter than reader expects.

Description

Reports || whose right operand starts with && without parentheses: a || b && c, a || b && c || d.

Rationale

&& binds tighter than ||, so a || b && c is a || (b && c). Read left to right, it looks like (a || b) && c. Guard done || empty && return never returns when done holds.

Example

state === nothing || values === nothing && return nothing

Alternative

(state === nothing || values === nothing) && return nothing

Limitations

a && b || c is (a && b) || c, as left-to-right reading gives; rule leaves it alone. Fix keeps meaning and adds parentheses: a || (b && c). Check that code means it.

annotation

Group readability, stage syntax.

Corset.Rules.Annotation — Module

annotation (F71): argument or result without type.

Description

Reports named function definition with untyped argument or no result type, once per method. Cause labels mark each untyped argument and missing result type.

Rationale

Signature is first thing reader sees. Types there say what function accepts and returns without reading body. Result annotation also acts as check: result-conversion reports annotation that converts.

Example

area(width, height) = width * height

Alternative

area(width::Real, height::Real)::Real = width * height

Limitations

Exempt: _ and unnamed ::T arguments, keyword splat (Julia rejects its type), anonymous functions, and local functions (closures). Abstract types are intended. ::Any accepts anything on purpose and opts out. Fix guesses types from inference: argument types package calls pass, literal default values, and result types. Each widens to its family (Real, AbstractVector{<:Real}, abstract supertype of struct). Argument guess is breaking: callers outside package can pass other types. Result guess is likely when inference covers every argument type: all arguments typed, keywords included, and no signature skipped. Else it is breaking. Keyword arguments, splats and destructured arguments keep manual fix. Method without package caller keeps it too. Script and run without package get no guess.

approx-zero

Group correctness, stage syntax.

Corset.Rules.ApproxZero — Module

approx-zero (F10): approximate compare to zero without atol holds only for exact zero.

Description

Reports x ≈ 0 and isapprox(x, 0) with literal zero and no atol. Test macro argument atol counts: @test x ≈ 0 atol = 1e-8 passes it to isapprox.

Rationale

isapprox uses relative tolerance by default. Relative to zero, no nonzero value is close, so test passes only when value is exactly zero.

Example

converged = residual(x) ≈ 0

Alternative

converged = isapprox(residual(x), 0; atol = 1e-8)

Limitations

Rule sees literal zero only. Zero held in variable passes.

baked-state

Group correctness, stage syntax.

Corset.Rules.BakedState — Module

baked-state (F100): precompile bakes run-time value into global.

Description

Reports global assigned at module top level from expression that reads run-time state, in package code only. State: thread count, ENV, home, working and temporary directory, clock, random numbers, host name, process ID, pointers. Top level spans module body, begin, if, ternary, &&, ||, global in let, @static and @eval. Function bodies, closures and __init__ run later and pass. Arguments of other macros pass: macro decides whether they run. Scripts never precompile, so rule skips them.

Rationale

Precompile runs module top level once and stores globals in cache. Each later session loads value of build session: wrong thread count, old path, null pointer.

Example

const NTHREADS = Threads.nthreads()

Alternative

const NTHREADS = Ref(0)
__init__() = NTHREADS[] = Threads.nthreads()

Limitations

Rule sees state read inside assigned expression. Value passed through local variable, or read in if condition, passes. Assignment in top-level for, while or try passes. Closure called at once, as in foreach(f) do … end, passes.

bang-convention

Group correctness, stage effects.

Corset.Rules.BangConvention — Module

bang-convention (F53, F86): method writes argument or global state without !, or ! method writes nothing.

Description

Reports package method whose function name has no !, but whose code writes caller-visible state (missing):

  • memory of argument, of global, or of object no binding names;
  • task-local storage.

IO, RNG, synchronization and iteration writes need no !. Write to non-public package global that no other package method reads or writes is cache: it needs no !. Method added to Base function may write its subject (first argument not declared callable) when callers trust name for it: IO function on IO, RNG function on AbstractRNG, iterate on stateful iterator, synchronization function. Other writes there need ! as above: close on type that is not IO writes what callers cannot see. Reports package method of ! function that compiler proves writes nothing, and whose result is new value (spurious). Result nothing, argument, or value that holds or lies below argument passes: hook, or method with nothing to change. !! functions (mutate when possible) and sizehint! (hint) pass.

Rationale

Caller reads ! as promise that call can change argument. Missing ! hides write, and Corset name trust misses it in callers too. Spurious ! makes caller drop result, which holds new state.

Example

normalize(v::Vector{Float64}) = (v ./= sum(v); v)

Alternative

normalize!(v::Vector{Float64}) = (v ./= sum(v); v)

Limitations

Fix is manual: rename definition, call sites and exports by hand. Constructor and callable object pass: their name cannot take !. __init__ passes: it sets state once, at load. Macro passes: it owns expression it rewrites. iterate may write its state: loop passes state back and sees nothing else. Write that only may happen (possible) gives no finding. spurious needs compiler proof of no write for every unit. Method that always throws on stand-ins passes.

banned

Corset.Rules.Banned — Module

banned (F82): code matches project ban.

Description

Reports code that matches banned entry in [preferences.Corset]: Argus pattern, or name regex over bound names. Name regex must match whole name; bound names are parameters, assignment targets, loop variables, definition names and fields. Each entry gives reason, which finding shows. All entries share one level, as Clippy disallowed_methods.

Rationale

Project rules outside Corset footguns: house conventions, retired APIs, caution markers such as ccall that need review.

Example

[preferences.Corset]
banned = [
    { pattern = "@show({_}...)", reason = "debug print; use `@debug`" },
    { name = "tmp.*", reason = "name what value holds" },
]

Alternative

Follow reason of entry.

Limitations

Patterns match syntax as written: alias or import under other name passes.

broad-catch

Group safety, stage syntax.

Corset.Rules.BroadCatch — Module

broad-catch (F59): catch handles every error.

Description

Reports catch block that neither tests error type nor passes error on.

Rationale

Bare catch also catches InterruptException, OutOfMemoryError and bugs such as MethodError, then hides them.

Example

value = try
    parse(Int, text)
catch
    0
end

Alternative

value = try
    parse(Int, text)
catch error
    error isa ArgumentError || rethrow()
    0
end

Limitations

Rule accepts isa test on caught variable, rethrow, throw and error as narrowing. It does not check that test names right type.

broadcast-rebind

Group performance, stage lifecycle.

Corset.Rules.BroadcastRebind — Module

broadcast-rebind (F41): loop replaces buffer with new broadcast array each iteration.

Description

Reports broadcast (x = f.(x)) in loop that replaces array allocated before loop (rebind pair of lifecycle stage) when broadcast reads no array but that buffer, keeps its type, and no code sees old array after rebind. Fix assigns in place: x .= f.(x).

Rationale

Each iteration allocates new array and drops old one. In-place broadcast writes into buffer: one array serves whole loop.

Example

function decay(n::Int)
    x = ones(4)
    for _ in 1:n
        x = x .* 0.5
    end
    return x
end

Alternative

function decay(n::Int)
    x = ones(4)
    for _ in 1:n
        x .= x .* 0.5
    end
    return x
end

Limitations

Fix tier is likely: package call that keeps array but returns no array hides alias, and .= then changes array it keeps. Broadcast with array operand other than buffer passes: its axes can differ. Fix needs buffer and broadcast assigned to one plain name (x = ones(n), then x = f.(x)), and dot syntax or @. on right side; else fix is manual.

closed-struct

Group composability, stage package.

Corset.Rules.ClosedStruct — Module

closed-struct (F84): public struct has no abstract supertype, so users cannot add sibling types.

Description

Reports definition of struct with supertype Any when public name refers to it. Public names are names root module exports or declares public, and public names of submodules those names reach.

Rationale

Methods typed on concrete struct accept only that struct. User who needs variant cannot subtype it and must copy or wrap it. Abstract supertype gives users one type to subtype and package one type to dispatch on.

Example

export Model
struct Model
    weights::Vector{Float64}
end
predict(model::Model, x::Vector{Float64})::Float64 = model.weights' * x

Alternative

export AbstractModel, Model
abstract type AbstractModel end
struct Model <: AbstractModel
    weights::Vector{Float64}
end
predict(model::AbstractModel, x::Vector{Float64})::Float64 = model.weights' * x

Limitations

Rule reads struct forms in package files; struct from macro without struct form passes. Public alias counts: const Pairs = Table{Pair} makes Table public.

constant-array

Group performance, stage lifecycle.

Corset.Rules.ConstantArray — Module

constant-array (F39): filled array that method never writes allocates every element.

Description

Reports zeros, ones, fill, trues or falses array of package method that method only reads: no write, resize, escape or φ join. Allocations and their events come from lifecycle stage. Fix swaps call for FillArrays.jl type and imports it above first statement of module code.

Rationale

Array that holds one value in every element needs no memory per element. FillArrays.jl Zeros, Ones, Fill, Trues and Falses store value and axes only, and many functions take shortcuts on them (sum, *).

Example

weighted(x::Vector{Float64}) = x' * ones(length(x))

Alternative

using FillArrays: Ones
weighted(x::Vector{Float64}) = x' * Ones(length(x))

Limitations

Fix tier is likely: callee that requires Array rejects lazy array, and package must add FillArrays.jl to its dependencies. Call that inference cannot place, module that binds same name to other value, and one-line module get manual fix.

double-include

Corset.Rules.DoubleInclude — Module

double-include (F64): same file included twice.

Description

Reports second and later include of same file in one run, and include of entry file Julia already loads (module file, extension, test entry). Paths resolve as discovery resolves them: string literal, raw string, @__DIR__, and joinpath of those.

Rationale

Each include evaluates file again. Struct definitions then throw on redefinition, and methods are defined twice. Including entry file loads it twice, or recurses until stack overflows.

Example

Alternative

Include each file once, from module root file.

Limitations

Computed paths pass.

false-effects

Group correctness, stage effects.

Corset.Rules.FalseEffects — Module

false-effects (F58): own analysis contradicts @assume_effects claim of package method.

Description

Reports package method whose @assume_effects claim effects stage disproves:

  • :effect_free: method writes memory caller sees.
  • :inaccessiblememonly: method writes memory caller sees, or reads global or task state.
  • :notaskstate: method reads or writes task-local state, default RNG or ScopedValue.

Rationale

Compiler trusts claim without check. False claim lets compiler delete, move or constant-fold calls, so code misbehaves only after optimization, and only in some builds.

Example

const CALLS = Ref(0)
Base.@assume_effects :effect_free function scaled(x::Float64)
    CALLS[] += 1
    return 2x
end

Alternative

const CALLS = Ref(0)
function scaled(x::Float64)
    CALLS[] += 1
    return 2x
end

Limitations

Rule checks claims on method only; claim on block inside method passes. Rule cannot check :consistent, :nothrow, :terminates_globally, :terminates_locally, :noub and :nortcall. Read of global state breaks :consistent only when read value reaches result; facts do not trace that. Read of argument memory passes :inaccessiblememonly check: access fact cannot tell mutable argument from immutable one. Finding takes certainty of access that contradicts claim.

guard-result (F114): function result is value of && or || guard.

Reports guard as last value of named function, long form or short form. Guard: chain whose last term exits. || guard gives true when it passes; && guard gives false.

hidden-input

Group correctness, stage effects.

Corset.Rules.HiddenInput — Module

hidden-input (F55): method reads default RNG, or package state that other package method writes.

Description

Reports package method that reads input no argument passes:

  • default RNG: rand(), randn() or shuffle!(v) without RNG argument;
  • object in package global that other package method writes: const SCALE = Ref(1.0) that set_scale! sets.

Default RNG read passes when caller controls RNG: package method of same function takes RNG argument beside same arguments (f(rng, x) beside convenience method f(x) = f(default_rng(), x)), or method takes RNG keyword (f(x; rng::AbstractRNG = default_rng())). Method that takes RNG and draws without it gets finding. Read through call to package method that reads same input passes: callee gets finding. Method that writes global it reads passes: bang-convention covers it.

Rationale

Result depends on state caller cannot see or set. Test cannot fix seed per call, and concurrent callers race on state.

Example

jitter(x::Float64) = x + randn()

Alternative

jitter(rng::AbstractRNG, x::Float64) = x + randn(rng)
jitter(x::Float64) = jitter(Random.default_rng(), x)

Limitations

RNG keyword that keyword body reads passes, even when body draws default RNG too: facts leave out generated methods. Untyped RNG argument or keyword counts for none: declare rng::AbstractRNG. Sibling that only seeds its RNG argument counts as drawing from it: facts give one kind to every RNG access. Global no package method writes passes: lookup table stays constant. Write in __init__ sets state once, so it passes too. Cache write passes: cache read is invisible to caller. Task-local storage and ScopedValue reads pass: logging reads both for every message. Finding takes weaker certainty of read and write: global that other method may write gives possible finding. Write to other path below same global gives possible finding, unless constant values settle both paths. Read through mutable holder or non-constant global that now holds written object gives possible finding: code can repoint it. Read of one field of mutable object gives finding when other method writes other field: facts name objects, not fields.

impure-lambda

Group correctness, stage effects.

Corset.Rules.ImpureLambda — Module

impure-lambda (F56): anonymous function writes state inside call of Base query function.

Description

Reports call of Base function without ! that calls function argument (map, filter, sum, sort with by) when its anonymous function writes state: captured variable, method argument, or global. Function that writes only objects it creates passes. foreach, functions with ! and ordered folds (foldl) pass. Named function passes: name with ! states write (bang-convention).

Rationale

Query function promises result only: order and number of calls to its function are Base detail. Write then depends on Base internals, and call that reads as query changes state.

Example

function first_seen(items::Vector{Int})
    seen = Set{Int}()
    return filter(item -> item in seen ? false : (push!(seen, item); true), items)
end

Alternative

function first_seen(items::Vector{Int})
    seen, kept = Set{Int}(), Int[]
    for item in items
        item in seen || (push!(seen, item); push!(kept, item))
    end
    return kept
end

Limitations

Call facts merge writes of closures call invokes: named callable argument that writes gives finding too. Write through local assigned twice, or call with stand-in operand, gives possible finding.

intermediate-widening

Group performance, stage inference.

Corset.Rules.IntermediateWidening — Module

intermediate-widening (F87): literal or constant makes intermediate run in wider type than input.

Description

Reports weak value that meets generic float input and widens intermediate value, while returned and stored values keep their type: conversion or concrete store narrows result again. Weak values as in type-disruption, which reports widening that escapes.

Rationale

Float32(x * 0.5) computes product in Float64, then rounds back. Work in wider type is slow on GPU and halves SIMD width.

Example

half32(x::AbstractFloat) = Float32(x * 0.5)

Alternative

half32(x::AbstractFloat) = Float32(x * oftype(x, 0.5))

Limitations

Fix converts weak value to input type as type-disruption fix does. It changes rounding of intermediate, so it can change result in last bit. Integer input is exempt, as in type-disruption. Finding is possible when method branches on type or span cannot show weak value.

invariant-parameter

Group correctness, stage package.

Reports function that package module creates under name of exported Base function, such as show or length. Module gets separate function of same name, so Base function gains no method. Finding is definite for operators and Base interface functions when each signature names package type; otherwise possible.

Rationale

Method meant to extend Base function lands on new function. Callers outside module call Base.show and never reach it. Inside module, name no longer reaches Base function: show(stdout, 1) throws MethodError. Julia 1.13 raises no error. Packages also shadow names on purpose, such as own parse for file format; Corset cannot tell intent there.

Example

struct Square
    side::Float64
end
show(io::IO, square::Square) = print(io, "Square(", square.side, ")")

Alternative

struct Square
    side::Float64
end
Base.show(io::IO, square::Square) = print(io, "Square(", square.side, ")")

Limitations

Rule sees exported Base names only. Interface list holds functions that Julia manual interfaces ask types to extend, plus display, comparison and conversion. Fix qualifies each method with Base. only when each signature names package type; otherwise method on Base function would be type piracy, and fix is manual.

stateful-reuse

Group correctness, stage effects.

Corset.Rules.StatefulReuse — Module

stateful-reuse (F51): method starts iterator twice, or lets it escape after start, where its type admits stateful iterator.

Description

Reports second start of one iterator on one path, and iterator that escapes after start or starts after escape. Start: iterate without state, for loop, destructuring, first, only, generic isempty, consuming call (collect, sum, map, …), or zip operand. Escape: return, store, operand ! call does not write, or operand of package function. Start inside loop restarts on each pass, unless loop makes new object each pass. Rule checks type that can hold stateful and multi-pass iterators both: abstract type other than AbstractArray, AbstractDict, AbstractSet, AbstractString, Tuple, NamedTuple, Pair, Number or AbstractChar; struct with field of open parameter type (inner::T), to which iteration can pass; or union of both kinds. One object and definite starts give definite; overlapping objects, or isempty that other methods can serve, give possible.

Rationale

Generic code that restarts its argument works on vector and loses elements on stateful iterator such as Iterators.Stateful or eachline result: first consumes first element, so loop after it starts at second element. Iterator that escapes after start hands consumed state to other code. Tests with arrays do not show this.

Example

function total(itr::Any)
    isempty(itr) && return 0
    s = 0
    for x in itr
        s += x
    end
    return s
end

Alternative

function total(itr::Any)
    peeled = Iterators.peel(itr)
    isnothing(peeled) && return 0
    first, rest = peeled
    s = first
    for x in rest
        s += x
    end
    return s
end

Limitations

Lazy wrapper (enumerate(itr), Iterators.take(itr, n)) starts nothing until code iterates it; rule sees no start there. zip starts its operands where code consumes it or lets it escape. Concrete type and known stateful type pass: code that restarts eachline result consumes lines on purpose. Call that only specialized method serves (minimum(d::Distribution)) goes to coverage line: its body decides start. Package method beside generic one makes start possible, unless argument admits Iterators.Stateful and package method cannot take it. Struct with parameter inside field type (items::Vector{T}) goes to coverage line too: its iterate body decides kind. Rule sees methods inference reaches, as never-succeeds does. Fix is manual.

type-disruption

Group composability, stage inference.

Corset.Rules.TypeDisruption — Module

type-disruption (F5, F6, F16): literal, constant, type name or hard-coded Array changes type of input that method returns or stores.

Description

Reports weak value that meets generic float input and changes type of value method returns or stores in argument, global or local container method returns. Weak value: number literal, constant, call of weak values only (sqrt(2), 2π), variable assigned one, or conversion to wider Base float type (Float64(x)). Weak value must keep float input type, as Python scalars do in NumPy 2. Also reports hard-coded Array (zeros(n), Vector{T}(undef, n)) in method with input array, when method returns or stores it, or mixes it with input array (possible).

Rationale

Generic method should give back caller's number type. x * 0.5 turns Float32 into Float64, which doubles memory and leaves GPU fast path. Float literal close to π or sqrt(2) widens too, where irrational constant would take input type. Array built with similar of input keeps GPU, static and offset array types; hard-coded Array drops them.

Example

scaled(x::AbstractFloat) = x * 0.5
function total(xs::AbstractVector{<:Real})
    s = 0
    for x in xs
        s += x
    end
    return s
end
halves(xs::AbstractVector) = fill(0.5, length(xs))

Alternative

scaled(x::AbstractFloat) = x * oftype(x, 0.5)
function total(xs::AbstractVector{<:Real})
    s = zero(eltype(xs))
    for x in xs
        s += x
    end
    return s
end
halves(xs::AbstractVector) = fill!(similar(xs, Float64, length(xs)), 0.5)

Limitations

Rule sees methods inference reaches, with stand-in types for generic arguments. Integer input is exempt: Julia promotes small integers to Int on purpose (sum(Int32[1]), index math). Store into concrete element, dictionary value or field type converts value; intermediate-widening reports work in wider type there. Base callees count as type-preserving. Finding is possible when method branches on type or span cannot show weak value. Hard-coded Array gets no finding in method without input array, and none for rand, collect or array literal. Fix converts float weak value to input type: T(0.5), oftype(x, 0.5) or eltype(xs)(0.5). float wraps type when declaration admits integers, since oftype(1, 0.5) throws. Fix tier is likely: callers see input type. Fix stays manual for irrational value, start value, conversion, product 2.0x, reassigned argument, and code inside macro other than @inline, @inbounds and similar. Fix builds hard-coded array from input: zeros(n) gives fill!(similar(xs, Float64, n), 0.0), Vector{T}(undef, n) gives similar(xs, T, n). It stays manual for computed fill value, type without parameter and no dimensions.
